# AI News // Live

A modern, source-first newsroom focused **exclusively on artificial intelligence**: LLM providers, frontier models, research, agents, infrastructure, open source, business, safety, compliance and ethics.

The project is a static GitHub Pages application with a GitHub Actions news pipeline. Headlines and short excerpts are refreshed from curated RSS/Atom sources; every story links to the original publisher. Full articles and social posts are not copied.

## What is included

- 40+ curated AI sources across primary labs, research, independent journalism and governance/standards
- **18-provider LLM Wire** covering OpenAI, Anthropic, Google DeepMind, Microsoft AI, Meta AI, xAI, Mistral, Cohere, Perplexity, Alibaba Qwen, Moonshot/Kimi, DeepSeek, Z.AI/Zhipu, MiniMax, AI21, Amazon AI, NVIDIA and IBM
- Provider-aware story tagging and filtering across first-party and independent coverage
- Official provider newsroom links
- Verified official LinkedIn / Instagram / Facebook profile links where available
- Dedicated **Compliance & Ethics / Governance Radar**
- EU AI Act implementation watch
- WAICO (World Artificial Intelligence Cooperation Organization) watch
- NIST, OECD, UNESCO, Council of Europe, IAPP and other governance sources
- Rich copyright-safe visual previews generated by the UI rather than copied publisher artwork
- Search, category filters, LLM-provider filters, source filters, sort modes and compact/grid views
- Signal Pulse trend calculation from the live dataset
- Local bookmarks
- Browser auto-refresh plus manual refresh
- Scheduled GitHub Action rebuilding `data/news.json` every 30 minutes
- Responsive PWA-style experience with offline shell caching
- No analytics or trackers by default

## AI News Copilot

Every story has an **Ask AI** action. The built-in research mode works without a backend and answers from the currently loaded headlines, short excerpts, tags and provider metadata. It can surface related stories, provider comparisons and governance/safety coverage.

An optional OpenAI-compatible chat-completions endpoint can be entered in the UI. Because GitHub Pages is static, server-side secrets cannot be protected there. The optional token is therefore kept only in the current browser session and is never committed to the repository or persisted by the app. For production use, connect the UI to a server-side proxy or another endpoint with appropriate authentication.

## Social and copyright policy

The social layer is intentionally conservative:

1. Official social profiles are linked only when they can be identified as official.
2. LinkedIn, Instagram and Facebook content is **not scraped**.
3. Social post text, photos, video and thumbnails are not copied into the repository.
4. A future social-post integration should use the platform's official API or embed mechanism and comply with its terms and publisher rights.
5. News cards display publisher headlines and brief feed excerpts only and always link to the canonical source.

## Architecture

- `index.html` — newsroom layout and interaction surfaces
- `styles.css` — responsive visual system
- `app.js` — filters, provider wire, trends, bookmarks and Copilot
- `config/sources.json` — curated source registry
- `config/providers.json` — LLM provider aliases, official newsrooms and verified social links
- `scripts/fetch-news.mjs` — RSS/Atom aggregation, AI-only filtering, provider matching and deduplication
- `data/news.json` — generated dataset
- `.github/workflows/refresh-news.yml` — validation + scheduled news refresh
- `.github/workflows/pages.yml` — GitHub Pages deployment

## GitHub Pages — important first-time step

The repository already contains a Pages deployment workflow, but GitHub does **not** let the repository Actions token create the Pages site for the first time. If the public URL returns **404**, perform this one account-level action:

**Repository → Settings → Pages → Build and deployment → Source → GitHub Actions**

After that, open **Actions → Deploy AI News to Pages** and run/re-run the workflow. Subsequent pushes and automatic news refreshes can deploy normally.

Expected project URL after Pages is enabled:

`https://chekento.github.io/Ainews/`

## Editorial principles

1. **AI only** — general-purpose feeds must pass a strict AI relevance filter.
2. **Source first** — primary/official sources are clearly distinguished from journalism and research.
3. **Provider aware** — LLM-provider coverage is tagged across all participating sources.
4. **Provenance** — every story carries its source class and canonical URL.
5. **Compliance isolation** — regulation, ethics, governance, standards and safety policy have a dedicated surface.
6. **Publisher respect** — headlines and brief excerpts only; no full-article mirroring or paywall bypass.
7. **Fail safe** — an unhealthy feed run does not overwrite the last healthy dataset.
