The interactive web UI and Android app include an **Ask AI** action for stories. The built-in local research mode works from the loaded headlines, brief excerpts, categories, provider tags and source metadata.

Useful questions include:

- Why does this story matter?
- Which current stories are related?
- How does this compare with competing LLM providers?
- What are the safety, ethics or EU AI Act implications?
- Which sources are first-party versus independent reporting?

## Privacy / secrets

No permanent API secret is committed to the repository or bundled into the Android APK. A connected external LLM endpoint should use appropriate authentication and preferably a server-side proxy for production use.
